# 第一批开发验证记录

阶段：`0.1.0-dev.1`，本地开发预览，尚未完成 V0.1 发布验收。

## 已实现

- 本地 Git 仓库、React/TypeScript/Vite、严格类型检查、格式化、测试与静态构建。
- Zod 数据校验、安全路径、JSON/Markdown 文件适配器、串行写入和 pending 恢复记录。
- 创建/打开本地 Workspace、最近目录、点击重新授权、同源写入锁、缓存不可用降级。
- Project 创建/重命名/归档/逻辑删除；Prompt 创建、正文编辑、自动保存、复制、人工状态、逻辑删除/恢复。
- 不可变版本、同内容去重、提交版本引用、查看版本、恢复前保护当前草稿。
- Launcher、三栏工作区、状态计数、当前项目标题/模型/标签筛选、基础 Markdown 预览。
- GitHub Actions 检查/部署骨架，项目站点 base、HashRouter、生产 CSP。

## 验证环境与结果

Windows，Node.js 22.20.0，npm 11.6.2。使用 Microsoft Edge 153.0.4234.48 运行 Playwright。

- `npm run typecheck`、`npm run lint`、`npm run test`、`npm run build` 已执行。
- 单元/集成测试：24 项，覆盖路径、坏 JSON/未来 schema、编号、无缓存重开、版本去重、提交引用、恢复保护、外部修改、事务中断、初始化恢复、逻辑删除、坏条目隔离、保存竞态和权限错误草稿保留。
- 浏览器测试：Launcher/Hash 刷新/无远程资源；合成目录中的创建 → 编辑 → 自动保存 → 版本 → 提交 → 恢复路径。
- 浏览器文件目录由测试专用内存句柄模拟，不属于原生目录选择/权限验证。缓存遇到合成句柄无法克隆时降级，是预期测试行为。
- `npm ci` 重新安装成功；`npm run format:check` 通过。运行中的 Vite 会占用 Windows 原生依赖，因此重装前需停止开发服务器。
- `/PromptDesk/` 子路径的生产构建通过本地预览验证：Hash 路由刷新、创建/编辑/保存、延迟加载编辑器、Markdown 预览及 CSP 生效，浏览器没有页面异常。
- 桌面 1440×900 与窄屏 390×844 使用合成数据检查，无横向溢出；截图仅保存在忽略的临时目录。
- 复制测试确认状态不变且多行中文内容保持；Windows 剪贴板使用 CRLF，比较时仅归一化平台换行，不改应用正文。
