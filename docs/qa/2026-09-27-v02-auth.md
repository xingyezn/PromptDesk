# V0.2 账户认证与 Production 验收

日期：2026-09-27  
实现：Better Auth 1.7.6 + Cloudflare Worker + D1；邮件功能按当前产品决定停用

## 验证范围

`npm run test:worker` 使用 Workers runtime 和隔离 D1 执行合成账户流程；当前构建不包含邮件发送器：

- 注册后无需邮箱验证即可登录；账户仍标记为未验证，但不会阻止登录。
- 登录 Cookie 包含 HttpOnly、SameSite=Lax、HTTPS Secure。
- 注销使会话失效；带当前密码删除账户后，账户行级联删除。
- 邮箱验证、验证邮件和密码重置路由固定返回 `EMAIL_FEATURES_DISABLED`。
- 跨源认证请求拒绝；超出 16 KiB 的认证请求体返回 413。
- 集成测试没有外部邮件请求。

## 尚未验证

- Production Worker 回滚流程和恢复演练。
- Resend sender verification、真实邮箱收件和验证链接点击未通过；按用户要求关闭邮件功能。
- 桌面 Chrome/Edge 对真实 HTTPS HttpOnly/Secure Cookie 的手测。
- 周期性 session token 轮换、过期会话边界及速率上限专项测试。
- 生产部署后的依赖、Network、日志和构建产物隐私审查。

本地 D1/Workers runtime 集成测试验证了 Cloudflare 兼容运行时中的业务链路，不代表 Cloudflare 生产环境已部署。

## Cloudflare 进展

- Wrangler OAuth 已完成，preview 与 production 各自创建 D1 并成功应用 migration 0001、0002。
- Preview Worker 已部署：<https://promptdesk-preview.openedutools.workers.dev>。
- 线上 `GET /api/health` 返回 `apiVersion=1`、`schemaVersion=2`；`GET /api/auth/get-session` 返回 HTTP 200 和空 session。
- Preview 最初配置了 Better Auth secret 和 Resend API key；只核对过 secret 名称，未读取密钥值。
- 最新 Preview 部署版本 `9ee2483c-761a-4779-9da0-46601bf575c2` 的健康接口返回 `apiVersion=1`、`schemaVersion=2`，未登录 session 返回 HTTP 200/null。Resend 合成收件地址注册曾返回 HTTP 200；真实收件邮箱验证请求返回 HTTP 503。Worker 有意隐藏服务商错误，无法区分 sender、recipient、权限或网络原因，也无法确认收件箱或链接状态。依照用户要求，现禁用全部验证与邮件发送功能。
- Production Worker 已部署到 <https://promptdesk-worker.openedutools.workers.dev>，版本 `4b3e25b5-989a-41f1-97df-cf89386c3363`；Preview 无邮件版本为 `a9d86e04-5a6c-4492-a0a6-5df7788695fa`。Preview 和 Production 均只保留 Better Auth Worker secret，没有 Resend secret。
- Production `GET /api/health` 返回 HTTP 200/schema v2；`GET /api/auth/get-session` 返回 HTTP 200/null。生产 HTTPS 浏览器验收使用 Microsoft Edge 153.0.4234.48 和 Playwright：合成账户注册后，浏览器接受并回传 HttpOnly、Secure、SameSite=Lax session Cookie；session endpoint 返回合成用户；密码重置路由返回 404；随后通过 UI 删除账户。D1 复查 `cookie-smoke-*@example.test` 合成账户数为 0。
- 当前不发送真实验证/重置邮件；没有收件箱验证或邮件链接点击记录。真实地址请求曾返回 503，Worker 为避免泄露服务商详情不会返回具体拒绝原因；产品按用户指示关闭邮件功能。
- 本地最终回归：typecheck、lint、format、76 项单测、3 项 Worker 集成测试通过；Playwright 开发态 11 项通过/2 项条件跳过，GitHub Pages 子路径构建 11 项通过/1 项条件跳过；Production HTTPS Cookie 测试在 Playwright Chromium 与 Edge 各通过 1 次。Worker 三环境 dry-run 通过。构建有约 500 KiB chunk 提示，但无构建错误。
