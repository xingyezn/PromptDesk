# V0.3 批次 B：项目视图、颜色、排序与打包

日期：2026-09-29。承接批次 A。用户澄清：**不要新建文件夹给项目分组**，而是让项目本身以「列表 / 文件夹卡片」两种样式呈现，颜色属于项目。据此修正并优化拖拽。

## 范围（修正后）

- B1 项目栏「列表 / 文件夹」只是同一项目集合的两种呈现方式：
  - 列表视图：一行一个项目，带颜色圆点、名称、归档标记。
  - 文件夹视图：网格卡片，卡片外形类似文件夹、按项目颜色着色。
  - 项目颜色为固定枚举（`slate/green/teal/blue/indigo/violet/pink/amber/red`），在项目设置里选择，不存任意 CSS。
- B2 项目与提示词排序优化：
  - 统一改用 Pointer Events，移除 HTML5 `draggable` 与 Pointer 混用导致的偶发冲突。
  - 拖动时来源项弱化（`dragging`）、目标项高亮（`drop-target`），并显示 `role=status` 文案「拖到目标项目/提示词上后松开；按 Esc 取消」。
  - 支持 Esc 取消；方向键排序保留；拖拽手柄增大到 22px 并加 hover 反馈。
- B3 个人空间与单个项目一键打包下载 ZIP：`GET /api/export?scope=project|space[&id=]` 只读返回项目/提示词/历史版本，前端 `fflate` 生成 `PromptDesk/<项目>/manifest.json`、编号 `.md` 与 `versions/` 快照。服务端不落文件、不含图片。
- migration `0004_project_color_and_order.sql`：`cloud_project.color/sortOrder` + `cloud_space(ownerId, revision, operation, updatedAt)`；schema 3→4。
