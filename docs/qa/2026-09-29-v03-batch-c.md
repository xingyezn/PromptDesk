# V0.3 批次 C：项目公开只读分享链接

日期：2026-09-29。用户确认：仅项目级、公开只读链接；未登录可查看、不可编辑、不显示历史版本；可撤销、单独限流、不泄漏 ownerId。

## 范围

- migration `0005_project_share.sql`：`cloud_share(id, ownerId, projectId, token UNIQUE, createdAt, revokedAt)`，`UNIQUE(projectId)` 每项目至多一条，复合 FK(projectId,ownerId) 级联删除；schema 4→5。
- 所有者 API（需会话）：
  - `GET /api/projects/:id/share` 返回 `{active, token, createdAt, revokedAt}`；撤销后 `active=false` 且不回显 token。
  - `POST /api/projects/:id/share` 创建或复用有效 token；已撤销时生成新 token；归档项目可分享，已删除项目返回 403。
  - `DELETE /api/projects/:id/share` 置 `revokedAt`，立即失效。
- 匿名只读：`GET /api/share/:token` 是本项目唯一的免会话业务读路径。
  - token 为 24 字节 URL-safe 随机能力串；未知/撤销/项目已删除均 404。
  - 按 IP 限流 120 次/分钟（复用 `rateLimit` 表，key `share-read:<ip>`）。
  - 只返回项目名/描述与未删除提示词的标题/正文，**不含** ownerId、版本、revision、nextVersion；响应 `cache-control: no-store`、`nosniff`。
- 前端：`/share/:token` 只读页（`SharedProjectPage`）不经会话即可渲染，复用 `MarkdownPreview`（禁图片/raw HTML）；项目设置内「分享链接」按钮读取状态、创建、复制链接、撤销。
